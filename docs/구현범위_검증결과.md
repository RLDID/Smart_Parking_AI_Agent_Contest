# 구현 범위와 기존 검증 결과

## 범위

단일 시설, 고정 합성 지도·관측·등록 계정·장치를 대상으로 합니다. 실제 로그인·역할별 API·SSE와 관계 관리, 사건/명령/계획/실행 이력, 차주 본인 위치·알림·응답을 연결했습니다. 권한·현재 상태·정책·근거·중복 요청을 실행 전에 검사하고 응답만으로 사건을 해결하지 않습니다.

기존 로컬 HTTP 시험은 제품 `084b284`, 합성 입력·가상 계정·mock 판단·임시 SQLite에서 각 1회 실행했습니다. 제공자 호출은 0회이며 5/5 통과했습니다.

별도 실제 모델 시험은 제품 `7a52a49`에서 GPT-6 Luna와 Gemini 3.8 Flash 각각 5장면×3회, 총 30장면을 통과했습니다. 모델별 짧은 watcher 세션에서 운영 명령 3주기를 확인했습니다. 로컬 ASGI·수동tick·합성 환경의 결과이며 장시간 현장 운용 성능이 아닙니다.

정식 화면은 실제 인증·권한별 조회·SSE·본인 위치·이력 페이지 이동·운영 단계·사건 수신/응답을 연결했습니다. 전체 화면·모바일·접근성·실제 청취 검증 완료를 뜻하지 않습니다.

## 적용 범위와 한계

- 단일 시설·고정 합성 지도에서 확인한 결과입니다. 실제 CCTV/YOLO·현장 장치·외부 연락·실제 신원 인증은 연결하지 않았습니다.
- 규정이 상충하는 경우 실제 모델 답변의 명시적 보류와 권한 근거가 부족한 사례가 있습니다.
- 전체 시나리오 수용, 장시간 운용, 모바일·접근성·실제 음향은 검증이 완료되지 않았습니다.
- 시험 결과는 위 버전·조건에 한정하며, 현장 정확도·사고 감소·관리 비용 절감 효과를 측정한 결과는 아닙니다.
